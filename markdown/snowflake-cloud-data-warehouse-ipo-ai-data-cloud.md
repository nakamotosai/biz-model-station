# Snowflake：云数仓重构者，2020年最大软件IPO，2026年转AI数据云

> 🛤 发家路径 | **云计算** · 美 · 巨头 · 直销+云市场（AWS、微软Azure、谷歌云）

## 🚀 起步缘由

三位创始人在Oracle和大数据库领域工作多年，深知传统数仓存储与计算耦合的痛点：扩容要预估容量、计算闲置时仍烧钱。他们从第一性原理出发，2012年在美国加州创立Snowflake，决定在公有云上重新设计数仓，让存储与计算完全分离、按需弹性伸缩，让用户用多少付多少。这一选择在当时被质疑是异端，却也成为后来云数仓的主流范式。

**创办人**：Benoit Dageville、Thierry Cruanes、Marcin Zukowski · **公司**：Snowflake Inc.

## 📈 发家里程碑

- **2012年7月** 创立与第一性原理验证（拐点）
  - Benoit Dageville、Thierry Cruanes曾在Oracle负责数据库性能，Marcin Zukowski则是苏黎世联邦理工学院的数据库研究员。三人在美国加州圣马特奥成立Snowflake，最初只有三名员工。他们决定放弃对Oracle式数仓的改良，转向云原生架构，为此没有沿用业界主流的Hadoop方案，把赌注压在切片存储和多集群计算上。
- **2014年6月** 产品发布（PMF）
  - Snowflake在亚马逊AWS上正式推出云数据仓库服务，客户只需把数据加载到对象存储，计算集群按查询需要启动和释放。早期客户多为中小互联网公司，但很快获得口碑。2015年至2016年，Snowflake确认了存储与计算分离的架构能同时解决扩展性和成本问题，付费客户与用量持续攀升，完成了从实验产品到可销售服务的验证。
- **2018年10月** 融资扩张（增长）
  - Snowflake完成4.5亿美元F轮融资，估值达到39亿美元，红杉资本等机构参与。2019年6月再获4.79亿美元融资，估值升至125亿美元，成为当时全球估值最高的云数据库创业公司之一。同期公司把销售重心从开发者个人转向企业采购，建立了直销团队，并在AWS之外支持微软Azure和谷歌云，降低客户采用门槛。
- **2020年9月** IPO（转折）
  - 2020年9月16日Snowflake在纽约证券交易所上市，发行价120美元，首日收于253.93美元，市值约700亿美元，融资约33.6亿美元，成为当时软件业规模最大的首次公开募股。创始人及早期员工获得巨大回报。但上市后市场对高估值的质疑从未停止，股价随后进入剧烈波动期，这也倒逼公司用持续收入增长来证明自己。
- **2023年5月** 收购Neeva失败（失败）
  - Snowflake在2023年5月宣布收购搜索引擎创业公司Neeva，但Neeva依赖的消费者搜索业务因付费用户规模不足，已经在2023年4月停止运营。Snowflake收购后主要吸收其团队和LLM技术，将其用到企业数据场景。这笔收购被视为一次方向性尝试的失败，因为搜索引擎本身没有带来持续收入，只换来了未必匹配的人才与模型经验。
- **2024年至2025年** AI数据云转型（拐点）
  - 2024年Snowflake推出Cortex人工智能平台，将大模型推理、向量搜索和企业级函数集成到SQL与表中，用户无需复制数据就能调用模型。2025年公司提出AI数据云战略，把数据平台定位从数仓扩展到非结构化数据与模型资产。此前公司被批评在机器学习领域落后Databricks，Cortex的推出被看作正面回应，也让AI收入第一次在财报中被单独强调。
- **2026年5月** AI收入加速与云厂商合作（增长）
  - 2026年5月28日Snowflake发布新业绩，AI产品增长显著，同时宣布与亚马逊扩大合作，市场对此反应积极，股价大涨。此前发布的2026财年财报显示营收增速约33%，净收入留存率126%。Snowflake从单纯数仓公司转型为AI数据云平台，成为少数能把AI预算转化为订阅收入的企业软件公司。
