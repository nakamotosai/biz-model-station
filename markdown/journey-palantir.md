## 🚀 起步缘由

2003年，Facebook创始人Peter Thiel与AI专家Alex Karp在旧金山创立Palantir，目标是为政府与企业提供大数据分析工具。

**创办人**：Peter Thiel, Alex Karp · **公司**：Palantir Technologies Inc.

## 📈 发家里程碑

- **2003** 创立（成功）
  - Peter Thiel与Alex Karp在旧金山创立Palantir，首次获得政府合同并获得风险投资。
- **2011** 推出 Gotham 与 Foundry（挫折/迭代）
  - Palantir推出Gotham与Foundry平台，虽然技术突破深度，但因政府合同限制和隐私争议导致收敛与重构。
- **2019** 直接上市（成功）
  - Palantir在纳斯达克完成直接上市，融资约12亿美元，市值突破60亿美元。
- **2023** 营收突破300M（增长）
  - 2023年Palantir营收达到约4.26亿美元，同比增长约45%，成为数据分析平台的主流选择。
