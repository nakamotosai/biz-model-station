# 罗宾汉零佣金革命：散户券商从GameStop风暴到加密翻盘

> 🛤 发家路径 | **金融科技** · 美 · 上市 · 线上

## 🚀 起步缘由

两位斯坦福校友曾在纽约量化自营交易公司做高频交易平台，亲眼看到机构用纳秒级速度赚散户的钱，而普通美国人买卖股票却要支付每次$10的固定佣金。他们想用技术把结算成本打下来，让任何人都能零门槛入市。2013年成立Robinhood时，团队在硅谷小公寓里写后端结算逻辑，以“金融民主化”为口号做移动端股票交易，最初被老牌券商嘲笑“散户不会真交易”。

**创办人**：Vladimir Tenev、Baiju Bhatt · **公司**：Robinhood Markets, Inc.

## 📈 发家里程碑

- **2013-2017年** 创立与种子轮（PMF）
  - 2013年4月成立，名字来自罗宾汉“劫富济贫”意象。12月以Index Ventures领投的$300万种子轮出街，Andreessen Horowitz、Nas、Snoop Dogg、Jared Leto先后跟投。2014年LA Hacks大会公开App原型，年底上架苹果内测，2015年3月全量上线。同年5月B轮$5000万，2017年4月C轮$1.1亿估值$13亿，移动端一键买单+SNS裂变让千禧一代迅速涌入，验证PMF。
- **2018-2020年** 期权与币圈扩张（增长）
  - 2017年12月开放期权交易，2018年2月抢先上线加密货币买卖（比特币、以太坊），比传统券商早半年以上；同年10月自建清算系统Robinhood Clearing，减少对第三方DTCC依赖。2018年5月D轮$3.63亿、7月E轮$3.23亿，估值升至$76亿。这时期“支付流（PFOF）”模式成型，向做市商Citadel、Two Sigma等收费以换取订单流，既补贴零佣金又埋下日后的SEC监管雷。
- **2021年1月底** GME冻结交易（拐点）
  - Reddit板块r/wallstreetbets散户抱团轧空GameStop，股价从$20飞涨至$483，对冲基金Melvin Capital巨额亏损。1月28日ROBINHOOD为确保清算所NSCC的保证金要求（从$7亿飙升到$37亿、后降回$14亿）被迫限制GME、AMC等股票买入，停止前只允许卖出。CEO Tenev凌晨4点电话联系Sequoia等股东紧急筹得$34亿救命钱，但48小时内App评分从4.8暴跌至1.2，国会罕见出现AOC与Ted Cruz同台谴责，品牌从“散户英雄”一夜变回“华尔街帮凶”。
- **2021年中-2023年** IPO与监管重锤（失败）
  - 2021年7月29日ROBINHOOD在NASDAQ上市（代码HOOD），募$21亿，市值$320亿，但上市后数周就跌破发行价。2021年6月因3月市场剧烈波动期间多次系统宕机、用户无法交易，被FINRA罚款$5700万并勒令赔偿，创FINRA史上最高单笔罚单。2022年8月裁员23%，2023年6月再裁7%；2022年11月FTX破产导致Alameda持有Robinhood 7.6%股权被美国司法部没收并以$6.05亿回购；tokenized stocks产品随即下架。2022年亦因未披露支付流收入被SEC罚款$6500万，累计监管支出超过$15亿。
- **2024-2026年** 加密全球扩张（转折）
  - 2024年3月收购期货经纪Marex FCM获美国CFTC注册，同步进入英国市场；2025年2月$3亿收购老牌财富托管平台TradePMR，推出AI投资辅助工具Cortex；2025年6月完成$2亿收购成立逾12年的欧洲老牌加密交易所Bitstamp，获MiFID与MICA牌照，欧盟上线代币化股票/ETF交易。2025年9月挤入S&P 500并推出交易者社交平台Robinhood Social；同年12月收购印尼两家经纪与加密牌照机构，布局东南亚。2026年3月Q1财报显示营收$10.67亿（同比+15%），净利息收入与加密货币收入分别占总收入约34%与13%，多元化收入架构初步成型。

- 2021年GME事件暴露清算准备金模型脆弱性：保证金需求峰值时接近违约，迫使高杠杆扩张的ROBINHOOD紧急暂停做市，损害用户信任并导致大规模提款
