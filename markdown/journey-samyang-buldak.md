# 三养辣鸡面：工业油丑闻濒死的老牌泡面厂，靠核弹辣度翻盘成全球网红

> 🛤 发家路径 | **餐饮/茶饮** · 韩 · 上市 · 混合

## 🚀 起步缘由

1961年韩国战后粮食紧缺，前保险公司高管全中允看到民众排队吃美军基地剩菜做的汤，坚信泡面能替代大米吃饱国民，以10韩元一碗的鸡肉面起步，成为韩国第一家泡面厂。初期靠朴正熙军政府建议把汤头改成辣味迎合韩国人口味，七十年代一度占据韩国泡面市场65%份额，跻身全国25大企业，1984年还在洛杉矶建厂服务韩侨，是把韩国泡面带向世界的先驱。

**创办人**：全中允（创始人，1961年创立）；金正秀（辣鸡面发明者，创始人儿媳，现任会长）；全仁壮（其夫，原会长） · **公司**：三养圆周率株式会社（Samyang Roundsquare Co., Ltd.，原三养食品）

## 📈 发家里程碑

- **1961-1963** 首碗面问世（PMF）
  - 全中允9月成立三养酪农公司，10月改名三养工业，1963年9月生产出韩国第一碗泡面，鸡肉口味10韩元一碗比咖啡还便宜，正好填补大米短缺的国民口粮缺口，从战后面包的替代品起步。
- **1970s** 垄断黄金期（增长）
  - 靠大关岭牧场和多元化扩张，三养拿下韩国泡面65%市场份额，挤入全国25大企业，1984年更在洛杉矶建厂瞄准韩侨，是当时最赚钱的韩国食品公司之一。
- **1989** 工业油丑闻（失败）
  - 匿名举报称三养用工业级牛油做面条汤包，即所谓牛油事件，虽然1997年最高法院最终未定罪，但消费者已经大规模流失，顶级食品科学家跳槽到竞争对手，农心和好侍趁机抢走市场，三养从龙头跌到第三第四名。
- **1997-2008** 金融风暴濒死（失败）
  - 1997年亚洲金融危机把还没洗清名誉的三养直接打入资不抵债，LA工厂关闭，公司进入还债求生模式，银行把股份当抵押品，十年间员工还在手写记账，竞品都数字化了三养还在手工录入，是公司最灰暗的十年。
- **1998** 少奶奶入行（转折）
  - 创始人全中允看着公司濒死，劝1994年嫁入全家的儿媳金正秀放弃家庭主妇身份到销售部上班，理由是做食品生意女人更细腻的视角可能有用，家族成员亲自下场能给员工做榜样，金正秀这年正式入职，没人想到她会成为救星。
- **2010-2012** 辣鸡面诞生（PMF）
  - 2010年金正秀带女儿在明洞一家炒辣鸡店吃饭，看到顾客热得扇舌头又痛又爽的表情，当场想到为什么不能把这种辣做成泡面，回去让首席食品科学家李秉勋反复加辣，做到研发总监都质疑这真的能卖吗，2012年辣鸡味泡面上市，初期零售反馈很差被嫌太辣，像个失败品。
- **2014** 视频引爆（拐点）
  - 2014年2月英国YouTuber Korean Englishman上传让伦敦亲友挑战三养辣鸡面的视频，老爸从真好吃变成狂灌牛奶鼻孔喷奶，视频拿下1100万播放，引发全球fire noodle挑战风潮，大胃王Matt Stonie一口气吃15碗的视频累计1.45亿播放，辣鸡面从滞销品变成网红爆款，出口开始起飞。
- **2020** 疫情红利（增长）
  - 新冠居家推动泡面需求暴涨，2020年三养销售额创历史新高，营业利润同比增长21.9%，同年推出泡菜味辣鸡面满足消费者对火鸡面系列的期待，BTS成员智旻被拍到爱吃辣鸡面又推了一波韩流带货。
- **2020** 挪用公款（失败）
  - 全仁壮和金正秀被判挪用公司约370万美元用于装修豪宅、租车和信用卡账单，全仁壮入狱，金正秀缓刑，退回赃款，案发于2019年1月全仁壮被判3年，金正秀被判2年缓刑3年，家族企业管理公私不分的老问题彻底暴露，大股东现代产业开发还推动过罢免两人董事资格。
- **2024** 丹麦召回（失败）
  - 2024年6月丹麦兽医食品管理局以单包辣椒素含量有急性中毒风险为由召回三款辣鸡面，最辣的三倍辣被维持召回，另两款一个月后经丹麦理工大重新评估解除，同年还被卷入2012年泡面价格垄断处罚案的新闻，食品安全标签再度被国际审视。
- **2026** 辣妈升会长（转折）
  - 2026年5月金正秀被任命为会长，6月正式上任，目标加速海外扩张，2月成为首位获韩国经营大奖的女性企业家，与丈夫以13亿美元身家登上福布斯韩国50富豪榜，4月退出三养圆周率董事会专注Buldak增长线，公司2025年营收约15亿美元，美国上半年1.85亿占海外三成，第四工厂6月投产年产能1亿包。
