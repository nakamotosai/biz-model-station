## 🕳️ 失败与踩坑

- 2021: 由于加州 PIPA 合规争议，Stripe API 暂停 2000 名商户，产生约 1 亿元收入损失。
- 2022: 监管调查导致 Stripe 在英国暂停部分支付功能，影响数十万用户。
