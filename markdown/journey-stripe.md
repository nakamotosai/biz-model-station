# Stripe：9行代码到千亿美金支付帝国

> 🛤 发家路径 | **金融科技** · 美/欧 · 巨头 · 线上/ToB/平台

## 🚀 起步缘由

兄弟俩在爱尔兰农村长大，十几岁时靠写代码已经挣到第一桶金。他们发现互联网公司接入支付很困难，即便硅谷创业者也常被银行和合规拖累。于是Patrick与John决定把支付抽象成API，让任何开发者几行代码就能收钱——这场始于兄弟车库的创业，把金融变成了开发者体验问题。

**创办人**：Patrick Collison、John Collison · **公司**：Stripe, Inc.

## 📈 发家里程碑

- **2007** 少年掘金（拐点）
  - Patrick16岁获爱尔兰青年科学家奖；兄弟俩先做了Auctomatic（拍卖后台工具），19岁时卖给CBC广播集团，完成了第一次退出。这笔钱既证明了技术变现能力，也把坑填平了：第一次创业并没有解决大问题。
- **2010** YC创立（PMF）
  - 两人搬到帕洛阿尔托，申请YC夏季班并入选。YC合伙人劝他们花几个月写商业计划，Patrick直接打开笔记本给Paul Graham看9行Python代码，PayPal老创始人Peter Thiel和Elon Musk当场投了200万美元天使轮。问题本身被技术解法打败，PPT反而成了最不重要的东西。
- **2012** 合规出海（增长）
  - 推出Stripe Connect，允许多市场收款，把平台型电商从自建支付中解放出来。此后Stripe开始在欧洲设点，把合规当成产品做：不是等市场合规再去卖，而是把合规能力内置进API，让卖家和开发者不必关心各国监管差异，这条路后来成为全球扩张模板。
- **2016** Atlas注册（转折）
  - 推Stripe Atlas——远程帮海外创始人注册美国Delaware C Corp。初衷是帮非美国创业者解决法律与银行开户噩梦，后来被Y Combinator等机构广泛采用。问题从支付延伸到怎么成立一家全球化公司，产品边界由此被打开。
- **2020** 疫情结构性红利（拐点）
  - 全球封锁导致线下支付崩盘，线上爆发。Stripe同时拿下Paystack（尼日利亚）、SEPA扩展和TaxJar，把非洲、东南亚与税务自动化同时并入版图。2021年完成6亿美元融资，估值冲到950亿美元；2022年内部估值却在利率与市场情绪下回调27%，并裁员14%。
- **2024-2026** AI+稳定币+并购（增长）
  - 重新开放USDC支付、收购Bridge进军稳定币、推出AI支付基础模型与Agentic Commerce Protocol，并在2026年以530亿美元联合收购PayPal的报价向市场宣告：支付基础设施仍是构建数字经济的原始桩。

## 🔀 转折点

- YC演示中9行代码代替商业计划
- Connect让平台电商把支付变成原生功能
- 把合规变成产品能力而非障碍
- 2022年估值回调触发内部审视与裁员，逼出后续效率化

## 🕳️ 失败与踩坑

- 第一版网站把保持接受邀请写成了不再接受注册，导致上线爆单时无法扩容；
- 2011年曾在代码中误放测试凭据，导致部分商家交易信息短暂暴露；
- 2022年市场回落时内部估值下跌27%，并遭遇14%裁员——过度乐观后的纠偏并不舒服。
