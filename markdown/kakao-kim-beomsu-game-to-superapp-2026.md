# 金范洙：从在线游戏小站到韩国超级app的缔造者

> 🛤 发家路径 | **其他** · 东亚（韩国） · 巨头 · 移动即时通讯+生态

## 🚀 起步缘由

金范洙1966年生于首尔贫寒家庭，父亲是笔厂工人，母亲做保姆，靠自己考入首尔大学。毕业后进三星SDS做程序员，干了数年后辞职。1998年创立网络游戏平台Hangame，赶上韩国宽带普及红利。2001年Hangame与搜索引擎Naver合并为NHN，金范洙任CEO。但在NHN内部与联合创始人战略分歧加剧，2007年离开自己创办的公司。此后赴美国寻找下个风口，看好移动互联网，2010年回到韩国推出KakaoTalk。

**创办人**：金范洙（Kim Beom-su）、沈浩秀（Seo Hyung-ook） · **公司**：Kakao Corp.

## 📈 发家里程碑

- **1998年** 游戏门户创业（拐点）
  - 金范洙辞去三星SDS工作，凑集资金创立在线休闲游戏网站Hangame，初始团队不足10人。创业初期现金流紧张，靠网吧推广和免费游戏模式吸引流量，但用户付费意愿低迷。金范洙通过差异化运营策略逐步扭亏，1999年实现收支平衡，成为他从企业人到创业者的关键拐点。
- **2001年** 平台合并（转折）
  - Hangame与韩国最大搜索引擎Naver合并为NHN，金范洙担任联合CEO。合并后NHN成为韩国最大互联网平台，2003年NHN在韩国证交所上市，市值快速攀升。但金范洙与Naver创始人李海珍在战略方向和管理风格上严重分歧，内部权力博弈持续多年，为后来金范洙离开埋下了伏笔。
- **2007年** 离开NHN（失败）
  - 在与Naver创始团队持续权力博弈后，金范洙从自己参与创建的NHN离职，远赴美国硅谷寻找新的创业机会。这段时期他从韩国最大互联网公司CEO变为无平台的创业者，在手机应用方向反复探索，推出的多个项目均未获得市场认同，是创业生涯最迷茫的一年。
- **2010年3月** KakaoTalk上线（PMF）
  - 2010年3月18日KakaoTalk正式上线，主打免费移动即时通讯功能，由金范洙与沈浩秀共同主导开发。凭借韩国极高的智能手机渗透率和通讯录社交链扩散机制，上线约9个月用户突破500万。早期没有清晰的盈利模式，团队依靠融资维持运营，但用户增长曲线极为陡峭。
- **2014年** 与Daum合并（拐点）
  - 2014年5月Kakao与韩国第二大搜索门户Daum宣布合并，10月成立Daum Kakao，金范洙出任CEO。合并后KakaoTalk用户超1.4亿，但整合过程及后续Daum原有搜索业务与移动端的资源分配矛盾突出。2015年公司更名为Kakao，金范洙开始以通讯录为核心搭建金融、出行、内容等生态。
- **2015-2018年** 生态扩张（增长）
  - Kakao陆续推出Kakao Pay、Kakao T出行、Kakao Bank银行等子业务，通过KakaoTalk入口导流形成超级app模式。腾讯和阿里分别在Kakao和Kakao Pay中参股，带来技术和资源支持。2017年Kakao Pay获阿里约2000亿韩元投资，Kakao进入高增长的黄金期。
- **2020-2021年** 跻身首富（增长）
  - 2020年新冠疫情期间，Kakao服务使用量激增，股价飙升。2021年金范洙以约96亿美元身家超越三星李在镕成为韩国首富，引发广泛关注。Kakao市值一度超过40万亿韩元，成为韩国最具影响力互联网公司。金范洙成为百年来韩国首位非财阀家族出身的首富。
- **2022-2023年** 监管危机（失败）
  - 2022年9月Kakao旗下通讯服务发生大规模宕机事故，全国数千万用户工作生活受阻，引发监管机构对平台依赖性的严重关切。同时韩国公平交易委员会启动对Kakao平台垄断行为的调查，质疑其利用通讯app入口挤压竞争者，市值短期内大幅缩水。

## 🕳️ 失败与踩坑

- KakaoTalk上线初期无盈利模式，靠融资维持，团队面临何时造血的质疑

## 📚 经验教训

- 创始人在合并中失去控制权是长期隐患，金范洙离开NHN的教训直接影响了后来Kakao的治理设计
