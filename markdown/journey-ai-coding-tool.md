> 🛤 发家路径 | **软件开发工具** · 美国 · 巨头 · 平台/插件

## 🚀 起步缘由

2020 年与 OpenAI 合作推出 Copilot，旨在通过大模型在 IDE 里即时生成代码。

**创办人**：Tom Preston‑Werner, Chris Wanstrath, PJ Hyett, David Filo · **公司**：GitHub

## 📈 发家里程碑

- **2020 年12月** 发布（首个 Beta 版发布）
  - 首个 AI 代码助手面世，支持 VS Code 和 GitHub 使用者。
- **2021 年6月** 正式（广泛集成）
  - Copilot 通过 VS Code、JetBrains 以及 GitHub Online 完全支持。
- **2023 年10月** 升级（多语言与插件化）
  - Copilot 2.0 推出多语言支持与无损插件，成为 IDE 插件主流。
