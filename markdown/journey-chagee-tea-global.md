# 霸王茶姬：张俊杰从流浪少年到美股茶饮第一股，国风鲜奶茶如何杀出茶颜悦色阴影

> 🛤 发家路径 | **餐饮/新茶饮** · 中 · 巨头 · 线下（加盟为主）+海外出海

## 🚀 起步缘由

创始人张俊杰的起点比绝大多数新茶饮创始人都要低。同龄人准备高考的年纪他还在流浪，前后长达七年，直到十七岁才进入云南一家名叫大维奶茶的连锁品牌当店员，靠表现一路做到云南区域运营负责人。后来他盘下大维一间濒临倒闭的加盟店，靠密集营销活动加上配送服务让这家店起死回生，这段经历既攒下了创业第一桶金，也让他第一次摸透了加盟门店的运营与翻盘逻辑。2015年他离开奶茶行业，加入上海一家做机器人的科技创业公司做海外销售，后升任亚太区市场主管。2017年前后新茶饮风口爆发，喜茶、奈雪、茶颜悦色纷纷跑出，张俊杰不想错过这扇窗，遂于2017年6月创办霸王茶姬，同年11月在昆明五一路开出第一家店。品牌名取自京剧《霸王别姬》，标识为水墨虞姬，打的是国风加原叶鲜奶茶的牌，但最初五年它被几乎所有投资人看作又一个茶颜悦色的山寨模仿者。

**创办人**：张俊杰 · **公司**：茶姬控股有限公司 CHAGEE Holdings Limited

## 📈 发家里程碑

- **2017年11月** 起步（PMF）
  - 首家门店在昆明五一路开业，主打原叶茶加鲜奶的国风鲜奶茶。彼时菜单上摆了水果茶、奶茶、芝士奶盖、芋泥、纯茶等近五十款产品，种类虽多却大多借鉴同行，视觉噱头重于复购。张俊杰才二十四岁，既没钱也没行业背景，只能靠在云南本地的连锁运营手感和对加盟商的理解慢慢滚雪球。
- **2018至2019年** 出海试水（拐点）
  - 国内门店不足一百家时霸王茶姬就把全球化写进核心战略并成立海外事业部，于2019年8月在马来西亚开出海外首店，随后进入新加坡、泰国。早期靠特许经营铺东南亚，但加盟管控薄弱、品牌形象粗糙，海外门店长期未形成规模效应，为日后新加坡2021年被迫撤出留下伏笔。
- **2020至2021年** 出省失败（失败）
  - 霸王茶姬尝试走出西南到广东、福建、安徽、湖南、上海零星开店，全部失败告终。2020年以18亿元估值寻求融资，被多数投资人以一眼学茶颜悦色为由拒绝；2021年在长沙开店更全军覆没。两度折戟暴露两大问题：品牌形象粗糙被加盟商当快招公司，数字化管理几乎为零连门店运营数据都收不上来。
- **2021年中** 成都战略（转折）
  - 拿下XVC、复星集团、琮碧秋实共计3亿元投资后，霸王茶姬把总部从昆明迁到成都锦江区，就地重构招聘培训绩效内控体系，从零搭建IT团队，开发出能按小时追踪每位店员效率的内控系统。加盟管理也从先开分店再建分公司改为先建分公司再开分店，把总部话语权一下顶满。同时从波导、华为、喜茶挖来一众高管补齐组织短板，张俊杰自己则从产品转向品牌营销与组织管理。
- **2021年9月** 品牌升级（转折）
  - 成都春熙路全国旗舰店开业，全面抛弃此前水墨虞姬的国风老形象，启用英文名CHAGEE、白底红色京剧花旦脸谱新标识，门店借鉴奢侈品店风格与中国古建筑榫卯结构。霸王茶姬内部将此次行动称为从小镇青年到都市青年转身的第一枪，核心目的是甩掉茶颜悦色山寨标签，与星巴克对标进入高端购物中心。
- **2022年** 聚焦单品（PMF）
  - 在XVC胡博予的追问下张俊杰狠下心砍掉水果茶主推线，把2017年上线的茉莉雪芽奶茶重新定名为伯牙绝弦作为核心大单品，菜单从近五十款收敛到鲜奶茶为主、价格带下探到15至20元。逻辑是奶茶是经过四十年长期验证的最大公约数、供应链简单可复制、能规模化扩张，茶汤含量高于鲜奶让消费者喝完不腻又摄入咖啡因提升复购。当年虽亏损约4800万元，仍持续砸钱到抖音小红书，为后续爆发铺好声量。
- **2023年** 全国爆店（增长）
  - 伯牙绝弦一年卖出2.3亿杯创下新茶饮单品销量纪录，单品销售额占比约三成。全年新增门店2317家，超过此前六年开店数总和，总店数反超喜茶。霸王茶姬以古茗约三分之一的门店数创造接近古茗七成的利润，全面逼到星巴克与瑞幸门口，瑞幸义乌加盟店被打到每天少卖七八十杯，被迫推出平替版伯牙绝弦的轻轻茉莉。
- **2024年** 海外重整（拐点）
  - 霸王茶姬在2024年初撤销新加坡特许经营转为公司直营，8月在乌节门重开引发排队热潮。产品上新四种店型体验门店、超级茶仓、24小时店、宠物友好店。全年净收入124.06亿元同比增长167.4%，净利润25.15亿元同比增213.3%，净利率达20.3%，单店月均GMV从2022年17.75万元升至51.17万元。但同店GMV增速从2023年94.9%骤降到2.7%，扩张见顶的信号首次被招股书正式披露。
- **2025年4月17日** 纳市上市（增长）
  - 霸王茶姬以CHA为代码在美国纳斯达克挂牌上市，花旗、摩根士丹利、中金、德意志银行担任承销商，成为中国茶饮美股第一股。创始人张俊杰当时三十岁，持股较大的A类B类普通股叠加XVC持股20.3%。募资主要用于扩大中国及海外门店、海外供应链与自动化研发。同年宣布2025年要在中国和全球净增1000至1500家店，并落子洛杉矶北美首店剑指星巴克。
- **2025下半年至2026年** 连串风波（失败/拐点）
  - 全球门店截至2025年2月突破6275家、会员1.77亿，但出海踩坑接连爆发。原计划2025年3月在越南胡志明市开首店，因App展示九段线地图被越南下架调查、招牌拆除、马来网友发起抵制，硬生生错失越南市场。2025年底被曝伯牙绝弦等高复购来自咖啡因成瘾性，张俊杰公开承认被舆论反噬，星岛日报报道市值一度跌14%。2026年1月手打奶茶摆拍视频登微博热搜，涉事福建漳州门店无限期停业整顿。原叶鲜奶茶的健康感叙事在舆论上首次大面积坍塌。
