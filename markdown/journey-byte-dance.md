## 🚀 起步缘由

ByteDance 2012 年由 Yiming Zhang 与 Rubo Liang 组建，起初定位为移动资讯聚合平台，随后凭借“今日头条”打响品牌。租赁公司在 2016 年推出抖音，1 年后完成国际化扩张，快速占领全球短视频市场。

**创办人**：Yiming Zhang, Rubo Liang · **公司**：ByteDance Ltd.

## 📈 发家里程碑

- **Aug 2012** 策划（成立）
  - 团队在四居室公寓组建，聚焦移动互联网初创机遇。
- **Aug 2012** 首发（推出）
  - 首款产品今日头条发布，快速引流用户并验证算法推荐模型。
- **Sep 2016** 抖音（突破）
  - 抖音上线后，用户参与度激增，形成以短视频为核心的内容生态。
- **Nov 2017** TikTok（全球化）
  - TikTok 正式上线，迅速在东南亚、拉丁美洲等地区占领市场份额，全球 MAU 超过 1.6B（截至 2025）。

## 🔀 转折点

- 2018 年 Musical.ly 合并入 TikTok，统一海外与国内短视频平台，形成全球化运营体系。
- 2019 年推行 Lark 企业产品，扩展至企业办公生态，开启 B2B 触点。

## 🕳️ 失败与踩坑

- 2021 年面临美国数据隐私诉讼，涉及用户数据泄露指控，后通过整改与法律谈判获得缓解。
