# Uber：从800美元黑车到Robotaxi帝国，13年烧百亿后盈利的共享出行活化石

> 🛤 发家路径 | **本地生活** · 美 · 巨头 · 平台

## 🚀 起步缘由

2009年Garrett Camp想做一个「更便宜更好叫的直达用车」服务，起因是他和Travis Kalanick跨年夜在旧金山叫私人司机花掉800美元觉得太贵，外加Camp曾在巴黎雪夜打不到出租车的痛苦记忆。Camp和几个朋友（Oscar Salazar、Conrad Whelan）一起搭出手机App原型，Kalanick起初只当「超级顾问」，公司名UberCab直白地标明它是一专车叫车服务。2010年2月Ryan Graves成为第一个员工并在5月当上CEO，同年12月Kalanick自己接任CEO、Graves转COO。创始定位反共识：出租贵且体验差、黑车贵且不透明，Camp看准中间那个「比出租贵一点但体验好得多」的缺口，用黑色轿车加1.5倍出租车价格切入高端商务出行，这是Uber最早的PMF。

**创办人**：Garrett Camp（加勒特·坎普）、Travis Kalanick（特拉维斯·卡兰尼克） · **公司**：Uber Technologies, Inc.

## 📈 发家里程碑

- **2009至2011** 起步（PMF）
  - 2009年3月公司成立，2010年5月在旧金山做beta版公测，2011年正式上线。最初只能叫到黑色豪华轿车、价格约为出租车的1.5倍，Kalanick坚信「优雅加效率」会比普通出租车吸引商务客。2011年因旧金山出租车运营商投诉，公司从UberCab改名Uber，为后来的品类扩张留余地。这阶段Uber靠一批核物理学家、计算神经科学家等很怪的早期雇员做抵达时间预测，把ETA算得比Google API还准，是它跑通「贵但靠谱」承诺的工程底座。
- **2012至2014** 平民化（增长）
  - 2012年7月推出UberX，允许非豪华车接入但一开始仍要求商业牌照；2013年4月在Lyft、Wingz、Sidecar先后拿到网约车合法许可后，Uber跟进把私家车车主接入UberX平台，大规模开放非职业司机，门槛一下子从「黑车」拉到普通家用车，是它从高端叫车走向大众出行的关键转折。2013年12月已覆盖65城，当月被USA Today选为年度科技公司。2014年8月又同时上UberPool合乘与Uber Eats外卖，把赛道从「打车」扩到「合乘加配送」，双轮雏形在此一年成型。
- **2016** 中国退场（失败）
  - Uber 2014年以「优步」之名进中国，与滴滴在补贴大战里烧到2016年上半年仅半年就亏超10亿美元，全球化总亏损也在2016年上半年突破10亿美元。2016年8月Uber把中国业务整体并入DiDi，换得滴滴约18%股权加滴滴反向投资Uber 10亿美元。这是Uber成立以来最显眼的战略级败退：进中国烧两年、烧掉几十亿，最终用换股承认打不赢中国本土对手。同年它还收购了自动驾驶卡车公司Ottomotto，创始人Levandowski被指从Waymo偷走商业秘密，埋下后来Waymo诉讼与自动驾驶自研失败的双重祸根。
- **2017** 危机年（失败）
  - 2017年是Uber的「至暗之年」。1月JFK机场出租车罢工反对穆斯林旅行禁令期间Uber被指趁机接单，#DeleteUber运动让超20万人删App，CEO Kalanick先是退出特朗普商业顾问委员会后又被迫下台。2月前工程师Susan Fowler发文揭露性骚扰与HR包庇，前总检察长Eric Holder介入调查，6月公司开除20余名员工、Kalanick在投资人压力下辞去CEO。3月纽约时报披露Greyball工具——Uber用地理围栏和信用卡库识别监管人员以在禁运城市逃避执法，伦敦交通局据此在9月拒绝续牌。同期2016年数据泄露事件被揭出：57百万客户与60万司机信息被黑，公司当初花10万美元封口，新CEO Khosrowshahi公开道歉，2018年Uber为此向FTC付1.48亿美元和解。8月Dara Khosrowshahi从Expedia接任CEO，Uber正式从「Kalanick颠覆者文化」切换到「Khosrowshahi合规合作者文化」。
- **2018至2021** 全球退守（失败）
  - Khosrowshahi接手后Uber加速从打不赢的市场退场换股：2018年2月把俄罗斯、亚美尼亚、阿塞拜疆、白俄罗斯、格鲁吉亚、哈萨克斯坦业务并入Yandex.Taxi并投2.25亿美元；3月把东南亚业务并入Grab换27.5%股权。2019年5月上市却遇上净亏85亿美元的年报，2019年夏天裁员8%并取消COO岗位。2020年5月疫情把出行业务打掉后又裁14%员工。2021年1月把烧多年没跑通的自动驾驶部门ATG以40亿美元卖给Aurora Innovation，Uber反向投4亿美元进Aurora——这是Uber承认「自动驾驶自研太贵太慢」的正式签字。同年10月花11亿美元收购酒类配送Drizly，却在2024年关门，并购未能跑通的隐性教训落在这阶段。
- **2019至2022** IPO加疫情（失败）
  - 2019年5月Uber以UBER代码在纽交所上市，发行价45美元，首日破发收41.58美元，市值从期待的1200亿美元跌到约700亿，是当年最令人失望的大型IPO之一。上市后Uber连续大额亏损：2019年净亏85亿、2020年净亏67亿、2021年净亏4亿、2022年净亏91亿（含所持滴滴等股权减值）。疫情期出行业务暴跌，靠外卖Uber Eats反向救场是Uber能活下来的关键——2020年收购Postmates加26.5亿美元、卖掉飞行出行Elevate给Joby、把印度Uber Eats卖给Zomato，一系列操作把现金烧到临界但保住了平台。这段时间Uber的生存哲学从「长成全球第一」变成「先把出行业务与外卖配送拧成对冲的双轮」。
- **2023至2025** 盈利反转（转折）
  - 2023年Uber实现首次全年经营盈利，净利18亿美元，结束自2009年以来连续14年的亏损叙事。2024年营收439亿美元、净利98亿美元；2025年营收520亿美元、净利100.5亿美元、经营利润55.6亿美元、月活2.02亿、日订单4200万、覆盖70国15000城、员工3.4万，Q4出行take rate 29.9%、外卖take rate 19.2%。期间它持续补合规与并购：2023年11月被荷兰DPA罚1000万欧元，2024年2月三千余起性侵诉讼被合并为MDL，2024年8月再被荷兰DPA因向美国服务器传欧洲司机数据判违反GDPR罚2.9亿欧元，2025年4月FTC起诉Uber One订阅未授权开通与取消困难，21个州加华盛顿特区同年12月加入修正诉状，2027年2月开庭。盈利不是终点，监管与安全仍是一条长尾账。
- **2026** 押注自驾（转折）
  - 2026年2月Uber收购停车位平台SpotHero并成立Uber Autonomous Solutions部门统一管理Robotaxi、自动驾驶卡车与人行道配送机器人。3月宣布向Rivian最高投12.5亿美元、计划2031年前部署5万台Robotaxi，并与Nvidia Drive合作用其自驾软件栈。此前2025年7月已向Lucid Motors与Nuro投超3亿美元买Lucid Gravity做Robotaxi，并签百度把Apollo自动驾驶车接入全球、与Pony.ai在克罗地亚落地欧洲首批Robotaxi、与WeRide在阿布扎比上线。9月又与Joby Aviation开空中的士与水上飞机。7月以148亿美元收购Delivery Hero把外卖帝国扩到欧亚拉。Uber卖掉ATG后再以「不自研、做平台调度分发层」的方式重新押注自动驾驶，是它从自研失败里学出来的路线修正：不和Waymo、特斯拉、百度在算法层硬拼，而做它们的上层入口。

## 📚 经验教训

- 全球化不是每个市场都硬打：中国、俄罗斯、东南亚Uber全部靠合并退场换股，承认打不赢就换股比硬烧到底更能保住股东价值，换来的少数股权日后还可能升值
- 创始人模式的激进文化能打规模但扛不住监管与信任危机，Kalanick的下台说明颠覆者走到一定体量必须换成合规者，换帅不是认输是组织长大的必经动作
- 数据泄露花封口费掩盖是最差的危机公关：Uber当初10万美元想压住，事后被罚1.48亿美元加CSO被刑事起诉，主动披露的代价远低于掩盖被揭穿后的总账
- 自动驾驶自研太贵太慢，卖掉ATG再以平台身份联盟多家Robotaxi比自研一条路线更稳，平台型公司不必硬做算法层也能拿住入口
- 共享出行从净亏百亿到年净利百亿用了14年，平台经济真正的盈利周期远长于融资叙事，估值修复不等于风险清零：FTC订阅诉讼与三千起性侵MDL仍在审判
- 双轮对冲不是口号：疫情期出行与外卖一崩一涨把Uber从破产边缘拉回，跨品类的反向相关性是平台型公司穿越黑天鹅最便宜的对冲工具
